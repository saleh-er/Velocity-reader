# ⚡ VelocityReader

**VelocityReader** is a high-performance PDF Research Assistant. By leveraging **Groq's LPU™ Inference Engine**, it provides sub-second responses to complex questions about your documents.

## 🚀 Features
* **Instant Inference:** Powered by Groq (Llama 3.3 70B) for lightning-fast chat.
* **Local Vector Store:** Uses ChromaDB and HuggingFace embeddings for privacy and speed.
* **Streaming UI:** A smooth, real-time typing experience built with Streamlit.
* **Context-Aware:** Only answers based on the content of your uploaded PDF.

## 🛠️ Tech Stack
* **LLM:** Groq (Llama-3.3-70b-versatile)
* **Orchestration:** LangChain
* **Vector DB:** ChromaDB
* **Frontend:** Streamlit
